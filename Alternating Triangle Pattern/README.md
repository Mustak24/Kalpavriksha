# Alternating Triangle Pattern

## Problem Statement

Write a C program that reads an integer `n` and prints a right-angled triangle of `n` rows. Row `i` contains exactly `i` symbols. Odd-numbered rows are filled with the character `*`, and even-numbered rows are filled with the character `#`.

## Constraints

- `1 ≤ n ≤ 10`
- Use nested loops and an `if-else` statement based on the row number.
- Do not print any extra spaces at the end of a line.

## Input Format

A single integer `n`.

## Output Format

`n` lines forming the triangle, as described above.

## Sample Input 1

```text
4
```

## Sample Output 1

```text
*
##
***
####
```

## Sample Input 2

```text
5
```

## Sample Output 2

```text
*
##
***
####
*****
```
